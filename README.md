# いくつもの明日

**[ブラウザで遊ぶ（ログイン不要）](https://keikeigoo.github.io/ikutsumono-ashita/)**

あなたが選ぶ、ひとつの人生。現代の日本を舞台にした、物語と選択肢を楽しむブラウザゲームです。

## 遊び方

- 主人公の名前とはじまりの性格を選び、16歳から物語を始めます。
- 仕事、学び、友情、パートナー、暮らしなどを選びながら、80歳まで32の節目を歩みます。
- 48の場面・192の選択肢・5種類の結末を用意しています。過去の選択が後の場面に影響します。
- 選択後は出来事を読み、「次の季節へ」で進みます。キーボードの1〜4でも選択できます。
- 「人生のしおり」から足あとを振り返り、文章として保存できます。

## 起動

依存パッケージやビルドは不要です。Python 3で、このフォルダを配信します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

ダウンロードした `play-offline.html` をブラウザで直接開いても遊べます。画像・物語をすべて含む単独のHTMLです。

## 保存とデータ

進行は使用中のブラウザのlocalStorageに自動保存します。サーバーへのゲームデータ送信はありません。別の端末やブラウザに移す場合は「設定」からセーブデータを書き出し、読み込んでください。ブラウザのデータ削除でセーブも消えます。

お金は選択による収支のみを記録します。自動的な給与や生活費の計算はありません。舞台・登場人物はフィクションです。

## 構成

- `dist/index.html`：ゲーム画面
- `dist/app.mjs`：画面と操作、自動保存
- `dist/engine.mjs`：進行・能力・分岐・セーブ検証
- `dist/story.mjs`：物語と選択肢
- `dist/style.css`：レスポンシブデザイン
- `dist/assets/town.svg`：オリジナルの街並みイラスト
- `check.mjs`：進行とセーブの検証
- `play-offline.html`：単独で動く配布版

## 動作確認

Node.js 18以降で実行できます。

```sh
node check.mjs
```

1,800回の進行シミュレーションで、全48場面・192選択肢への到達、80歳までの進行、5種類の結末、セーブの妥当性を確認します。ブラウザでも結末までの進行、自動保存からの再開、スマートフォン幅とパソコン幅を確認済みです。
